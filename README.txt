ПРАКТИКА — рабочая версия 0.3, 9 ноября 2026

БЫСТРО ПОСМОТРЕТЬ
Откройте https://imevstratov-pixel.github.io/praktika-tutor-studio/ в современном браузере. Для автономного файла сначала соберите исходники по инструкции ниже и откройте dist/index.html. Шрифт, стили и программа включены в этот файл; для его работы интернет не нужен.

На первом шаге вставьте текст лекции или выберите готовый пример. На втором проверьте темы, термины и опорные фрагменты. На третьем посмотрите первый вопрос и скачайте пакет JSON либо читаемое описание TXT.

Это PoC: встроенный разбор работает по правилам. Первый вопрос — пример по шаблону. Настоящие качество извлечения языковой моделью, учебный диалог и импорт пакета в действующий тьютор требуют отдельной проверки. Пакет JSON — наш текущий контракт, его ещё нужно согласовать с разработчиком тьютора. Учебные примеры адаптированы по открытым источникам; ситуации и числа вымышлены, это не транскрипты реальных лекций ШМК.

ХРАНЕНИЕ
Черновик сохраняется в этом браузере на этом устройстве. Режим приватного просмотра и настройки браузера могут ограничивать сохранение, особенно для локального файла. Скачайте итоговый пакет для надёжного переноса. Изменение исходного текста сбрасывает подготовленную структуру. Начало нового занятия требует подтверждения.

ЛОКАЛЬНЫЙ ЗАПУСК С МОДЕЛЬЮ
Для уже собранной версии нужен Node.js 20 или новее. Из папки «Практика» запустите:
  node local/server.mjs
Откройте http://127.0.0.1:4187. Для macOS также есть local/start.command. Остановка: Ctrl+C в окне запуска. Настройка Ollama или совместимого сервера подробно описана в local/README.md. Ключ хранится на сервере, в браузер он не передаётся. Пока модель не подключена, используется разбор по правилам.

ДЛЯ РАЗРАБОТКИ
Исходники React находятся в ui/. Требуется Node.js 24 (на этой версии проверена сборка). Из ui/:
  npm ci
  npm run dev
Страница разработки: http://127.0.0.1:4188. Для модельного режима параллельно запускайте local/server.mjs.
  npm run build:local
Сборка создаёт dist-v2/index.html и обновляет dist/index.html для локального сервера.
  npm run check
После сборки полный набор данных и сервера: npm test (из ui/). Для полной приёмки из чистого репозитория используйте npm run accept — он сам создаёт сборку до проверки сервера.
Смоук: npm run smoke. Полная приёмка: npm run accept. Первый раз установите тестовый браузер: npm run browser:install.
Правило приёмки, область покрытия и дальнейшая оценка модели: QUALITY.txt.
Проверка сервера: node --test local/server.test.mjs (из «Практика»).

ЧТО ИЗМЕНИЛОСЬ
Один маршрут из трёх шагов; пустой первый экран с понятным действием; редактируемые темы и словарь; обязательные термины; проверка источников; исключение ненужного материала; восстановление черновика; пример вопроса; отдельные скачивания; подробности графа и промптов раскрываются по желанию.

В графе темы и термины представлены узлами, а отношения — направленными связями. Выберите термин, чтобы увидеть его определение и дословные опорные фрагменты лекции. У графа есть масштабирование и поиск. Текст инструкции и JSON с данными курса копируются отдельно; скачиваемый промпт содержит обе части. Если браузер запрещает автоматическое копирование, интерфейс предлагает выделенный текст для ручного копирования.

Использованы настоящие исходники Fluid Functionalism и shadcn. Ссылки на registry, версии и перечень локальных изменений: ui/COMPONENTS.txt. Лицензии: ui/THIRD_PARTY_NOTICES.txt.
